# Lucho3D — Calculadora de costos

Calculadora web para estimar el precio de las piezas impresas en 3D. Permite cargar los gastos fijos del taller y los datos de cada pieza, y calcula el costo final con la ganancia aplicada.

## Qué calcula

- **Gastos fijos:** precio del filamento, precio del kWh, consumo de la impresora, vida útil, repuestos y margen de error.
- **Pieza:** horas y minutos de impresión, filamento usado e insumos extra.
- **Ganancia:** multiplicador personalizado sobre el costo.
- Opción para mostrar los resultados en pesos o en dólares.

## Uso

No necesita instalación. Abre `index.html` en el navegador.

## Tecnologías

HTML, CSS y JavaScript, con las fuentes Syne y Space Mono de Google Fonts.
